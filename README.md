# 微信小程序「Q 菜单」开发框架

这是一个原生微信小程序开发框架，完美复现了包含“分类管理、菜谱添加、购物车订单结算、微信分享拼单、熊猫随机选餐”等高颜值与强交互功能的私房菜点单应用。

本小程序**无需后端服务器支持**，所有数据读写和持久化都通过原生的**本地缓存 (WeChat Local Storage)** 实现，非常适合用于演示、离线测试与二次开发。

---

## 🚀 快速上手与运行指南

### 1. 准备工作
下载并安装官方的 [微信开发者工具 (WeChat DevTools)](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。

### 2. 导入项目
1. 打开“微信开发者工具”，在主界面点击 **“导入” (Import)** 按钮。
2. 选择本项目根目录：`/Users/a1/Documents/01Code/WeCt_Xcx`。
3. **AppID** 选项：如果您没有小程序 AppID，可以直接下拉选择 **“使用测试号” (Tourist AppID)** 进行本地开发预览。
4. 项目名称填写：“Q 菜单”。
5. 点击“确定”导入。

### 3. 本地编译与预览
* 导入后，开发者工具会自动进行编译，左侧模拟器将展示精美的小程序首屏。
* 您可以使用鼠标直接在模拟器上进行点击交互、滑动、调起相机和表单提交等所有动作。

## 💡 核心功能亮点与测试技巧

### 🛒 1. 模拟数据库 (无需联网)
小程序的全部数据存放在微信自带的缓存中。当您首次运行时，`utils/db.js` 会自动写入预设的 **“招牌私房菜”**、**“椒麻鸡”**、**“招牌红烧肉”** 等测试数据。
* **数据持久化**：即使您关闭开发者工具或重新编译，您添加的菜谱和订单依然存在。
* **重置数据**：如果您想清空全部测试数据，可在小程序的“我的”页面点击 **“恢复系统演示数据”**，一键还原为初始干净状态。

### 🐼 2. 熊猫“随机点餐”
在“厨房”页面右下角，有一只正在上下浮动喘气的可爱小红熊猫。
* **测试方法**：点击熊猫，弹出“随机点餐抽奖盘”，点击“帮我选一个！”，菜品卡片会高速滚动并最终通过振动挑选出一道随机菜品，您可以直接将其“加入购物车”。

### 👥 3. 邀请好友拼单 (微信分享)
小程序的购物车栏设计了“邀请好友下单”按钮。
* **测试方法**：在购物车有菜品时，点击“邀请好友下单”，可以调起微信原生的“转发给好友”弹窗。在开发者工具中，您也可以通过右上角的 “...” 转发，或者点击面板上的“分享”。
* **拼单识别**：当另一个模拟用户通过分享链接（包含 `?sharer=xxx` 参数）进入页面时，系统会提示“正在和好友拼单中”，并在确认订单页顶部显示“您正在加入好友的拼单中！”。

### ⚙️ 4. 权限与身份切换 (管理员 vs 普通吃货)
在“我的”页面顶部，有一个身份标签。
* **双角色体验**：
  * **管理员模式**：厨房页面右上角会展示“管理”和“+添加菜谱”按钮；并且在“我的”页面会展示“分类管理”与“添加菜谱”的快捷入口。
  * **普通吃货模式**：隐藏所有增删改的管理入口，给顾客提供最纯粹的挑选点餐体验。
* **切换方法**：点击“我的”页面中的 **“快速切换身份”** 选项，即可瞬间切换并更新 UI，方便进行闭环测试。

## 🛠️ 接入真实服务器建议

如果您后续需要上线并接入服务器：
1. 请将 `utils/db.js` 中的同步缓存读写操作（`wx.getStorageSync` / `wx.setStorageSync`）替换为微信网络请求 `wx.request`，调用您后端的 API。
2. 菜品图片上传：将 `pages/recipe-add/index.js` 中的本地临时路径，通过 `wx.uploadFile` 发送至您的云存储服务，返回真实网络 URL 后存入数据库。
3. 支付结算：将订单提交操作对接 `wx.requestPayment` 调起真实的微信支付。
